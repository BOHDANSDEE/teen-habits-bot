# Фінальні правила текстів картки

Цей файл — специфікація для генерації або перевірки спільної бази текстів HabitTeen.

## Загальна структура

Картка має п’ять **незалежних** текстових баз:

1. `Проблема` — 4000 унікальних варіантів.
2. `Вторинна вигода` — 4000 унікальних варіантів.
3. `Значення в житті` — 4000 унікальних варіантів.
4. `Афірмація` — 4000 унікальних варіантів.
5. `Результат` — 4000 унікальних варіантів.

У production для кожної з п’яти секцій робиться **окремий випадковий вибір**. Тексти не продовжують одну історію й не залежать від того, що випадково випало в сусідньому блоці.

Кожен окремий варіант може поєднувати кілька широких змістових осей, наприклад: життєва сфера + тип поведінки + широкий контекст. Це дає різні інтерпретації всередині одного короткого тексту, але не створює залежності між п’ятьма базами.

`🔎 Проблема: [назва рівня]` — не випадковий текст. Це тільки назва рівня, який вибрав користувач.

## 🔹 Проблема

- 2000 варіантів по 2 речення.
- 2000 варіантів по 3 речення.
- Просто й конкретно описує складність та її наслідок.
- Без рішення, поради або афірмації.
- Широкі теми: друзі, сім’я, навчання, гроші, самооцінка, час, стосунки, здоров’я, побут, майбутнє тощо.
- Орієнтир за обсягом: приблизно 2–2.5 мобільних рядка.

## 🪞 Вторинна вигода

- Рівно 2 речення у всіх 4000 варіантах.
- Перше речення називає конкретну коротку користь старого способу: уникнення конфлікту, критики, ризику, відповідальності, складного вибору, напруги тощо.
- Друге речення починається формулюванням: `Тому тобі вигідно залишатися у такому способі дій...`
- Це не наслідок проблеми й не рішення.
- Орієнтир за обсягом: приблизно 2–2.5 мобільних рядка.

## 🌟 Значення в житті

- 2000 варіантів по 1 реченню.
- 2000 варіантів по 2 речення.
- Показує широку сферу життя, на яку це впливає.
- Не повторює `Проблему` й не залежить від неї.
- Орієнтир за обсягом: приблизно 2–2.5 мобільних рядка максимум.

## 🔑 Афірмація

- 2000 варіантів по 2 речення.
- 2000 варіантів по 3 речення.
- Кожне речення від першої особи: `Я можу...`, `Я маю право...`, `Я обираю...`.
- Реалістична, без магічних тверджень.
- Орієнтир за обсягом: приблизно 2–2.5 мобільних рядка.

`🔁 Повтори афірмацію N разів.` — окремий службовий рядок. `N` випадково вибирається від 3 до 9 включно.

## ✨ Результат

Рівно 3 короткі речення у всіх 4000 варіантах:

1. Суб’єктивне полегшення в тілі.
2. Стало легше побачити інший спосіб дії.
3. Стало зрозуміліше, який наступний крок зробити.

Не обіцяти лікування або повне зникнення проблеми. Орієнтир за обсягом: приблизно 3–3.5 мобільних рядка.

## Компактність

Кількість видимих рядків залежить від ширини екрана й розміру шрифту, тому regression-тести використовують жорсткі межі символів:

- `Проблема` ≤ 125 символів;
- `Вторинна вигода` ≤ 130;
- `Значення в житті` ≤ 115;
- `Афірмація` ≤ 120;
- `Результат` ≤ 180;
- сума найдовших п’яти секцій ≤ 670 символів;
- повна Telegram-картка завжди < 4096 символів.
