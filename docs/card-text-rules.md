# Фінальні правила текстів картки

Цей файл — коротка специфікація для перевірки або генерації спільної бази текстів HabitTeen.

## Загальна структура

Картка має п’ять незалежних текстових баз:

1. `Проблема` — 4000 унікальних варіантів.
2. `Вторинна вигода` — 4000 унікальних варіантів.
3. `Значення в житті` — 4000 унікальних варіантів.
4. `Афірмація` — 4000 унікальних варіантів.
5. `Результат` — 4000 унікальних варіантів.

П’ять баз вибираються незалежно одна від одної. Вони не продовжують одну історію і не повинні логічно залежати від випадково вибраного тексту з іншої бази.

`🔎 Проблема: [назва рівня]` — не випадковий текст. Це тільки назва рівня, який вибрав користувач.

## 🔹 Проблема

- 2000 варіантів по 2 речення.
- 2000 варіантів по 3 речення.
- Просто й конкретно описує складність та її наслідок.
- Без психологічного жаргону.
- Без рішення, поради, афірмації або обіцянки результату.
- Теми широкі: друзі, сім’я, навчання, гроші, самооцінка, час, стосунки, здоров’я, побут, майбутнє тощо.
- Не будувати тексти навколо надто вузьких одноразових сцен.

## 🪞 Вторинна вигода

- Рівно 2 речення у всіх 4000 варіантах.
- Перше речення називає конкретну коротку користь від старого способу: уникнення конфлікту, критики, ризику, відповідальності, складного вибору, напруги тощо.
- Друге речення прямо пояснює, чому через цю користь людині вигідно залишатися у знайомому способі.
- Це не наслідок проблеми і не рішення.

## 🌟 Значення в житті

- 2000 варіантів по 1 реченню.
- 2000 варіантів по 2 речення.
- Показує широку сферу життя, на яку це впливає: навчання, друзі, сім’я, стосунки, гроші, здоров’я, майбутнє, самооцінка, побут, робота, цілі тощо.
- Не повторює текст `Проблеми`.
- База незалежна: наприклад, `Проблема` може бути про друзів, а `Значення в житті` — про навчання.

## 🔑 Афірмація

- 2000 варіантів по 2 речення.
- 2000 варіантів по 3 речення.
- Кожне речення від першої особи: `Я можу...`, `Я маю право...`, `Я обираю...`.
- Текст реалістичний, без магічних тверджень і обіцянок повного зникнення проблем.
- Дає дозвіл на нову поведінку, вибір, межі, спокійний крок або підтримку себе.

`🔁 Повтори афірмацію N разів.` — окремий службовий рядок і не входить у текст афірмації. `N` випадково вибирається від 3 до 9 включно.

## ✨ Результат

Рівно 3 речення у всіх 4000 варіантах:

1. Суб’єктивне полегшення в тілі.
2. Стало легше побачити інший спосіб дії.
3. Стало зрозуміліше, який крок зробити далі.

Не обіцяти лікування, повне зникнення проблеми або гарантований результат.

## Компактність

Картка має залишатися короткою й читабельною у Telegram. Поточні regression-ліміти:

- `Проблема` ≤ 350 символів;
- `Вторинна вигода` ≤ 270;
- `Значення в житті` ≤ 240;
- `Афірмація` ≤ 340;
- `Результат` ≤ 410;
- сума найдовших п’яти секцій ≤ 1600 символів;
- повна картка завжди < 4096 символів.
