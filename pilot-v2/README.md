# HabitTeen bot pilot v2

Пробна версія нового сценарію Telegram-бота. Вона не замінює старий курс у production: запускається окремою командою `npm run start:pilot`.

## Потік

1. `/start`
2. Один спільний блок: `⚡ Енергія та дії`
3. Три підблоки: `Лінь`, `Апатія`, `Прокрастинація`
4. У кожному підблоці поки один рівень
5. Після рівня бот збирає випадкову комбінацію з блоків:
   - Стан
   - Проблема
   - Вторинна вигода
   - Значення в житті
   - Афірмація
6. `💡 Хочу рішення` не повертає користувача в меню, а переводить у випадкову суміжну тему та дає новий фінальний розбір.

## Команди

- `npm run start:pilot` — запустити пробного бота
- `npm run demo:pilot` — вивести приклади всіх трьох підблоків без Telegram
- `npm run test:pilot` — перевірити структуру контенту й переходи

## Безпека

Токени та ключі не зберігаються в коді. Для запуску потрібен `BOT_TOKEN` у Environment Variables / `.env`.
